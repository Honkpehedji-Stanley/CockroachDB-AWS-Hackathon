Continuum

A follow-up agent with persistent memory: describe a symptom, send a lab report, come back in a future session — it still remembers.

  • Every conversation and document is stored in CockroachDB and persists across sessions.
  • Vector search over your history grounds every reply in what you've actually told it before.
  • Built for long-term follow-up, not one-off chats.

Not a diagnostic or treatment tool — a memory layer for following up over time.
